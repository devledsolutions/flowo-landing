Recorte da família original compartilhada pelo dashboard e pelo app. Geometria copiada sem alterações de `flowo-app` (`0831f4661709e89b9ee16632a907bdec4ba5d596`), `packages/brand-assets/icons/flowo-icons.json`; nomes seguem o mapa web da mesma revisão. `BadgePercent` usa `percent` e `MessageCircleMore` usa `message-text`.
