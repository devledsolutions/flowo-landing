## Pesquisa de demanda

- os termos exatos `sistema para barbearia`, `agenda para barbearia`,
  `software para barbearia`, `recepcionista virtual` e `IA para barbearia`
  ficaram abaixo do limiar de volume necessário para uma média estável;

  relativo médio 39, `agenda online` 8 e `sistema de agendamento` 3;

  limiar na mesma comparação.

O Google Trends usa uma escala relativa de 0 a 100 e exibe `0` quando o volume
é baixo demais, portanto esses números não equivalem a volume mensal absoluto.
Para SEO, a recomendação é usar páginas amplas de intenção
(`agendamento online`, `agenda online`, `sistema de agendamento`) como pilares e
manter `recepcionista com IA para barbearia` como diferenciação comercial,
long-tail e destino de campanhas.
